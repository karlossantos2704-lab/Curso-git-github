Lista de comandos básicos do Git

- git init: Cria um novo repositório Git ou Reinicia um repositório existente
- git clone: Copia um repositório Git de um local para o seu computador
- git add: Adiciona arquivos modificados ao histórico do repositório
- git commit: Registra as mudanças no histórico do repositório com uma mensagem
- git push: Publica o repositório local para um repositório remoto
- git pull: Sincroniza o repositório remoto com o local e atualiza o local
- git branch: Cria, Renomeia ou exclui uma nova branch
- git log: Exibe os registros logs de um commit
- git revert: Reverte alguns commits já existentes
- git resert: Redefine o HEAD atual para a condição determinada
- git show: Exiba os vários tipos de objetos
